# Scope — decided by the operator

This build implements exactly the features below. Anything under Deferred is
explicitly OUT of this build; do not implement it and do not stub it.

## In scope
- **White-label branding (name in header, title, footer)**
- **Light/Dark/System appearance setting, persisted**
- **Real auth, SSO (OIDC), RBAC, tenant isolation**
- **No-login persona switch (demo profile)**
- **Searchable catalogue, domains, recommendations**
- **Course content: video, downloadable reading, quizzes**
- **Quiz -> certification test -> certificate**
- **Completion-gated feedback with provider reply thread**
- **AI-built learning roadmap**
- **Wishlist + calendar progress view**
- **Registered learner dashboard**
- **Course-provider dashboard**
- **Platform-owner dashboard**
- **Exportable dashboards**
- **Audit log, data export/erasure, consent, legal**
- **Public marketing website**
- **Boot/migrate/health/profiles**

## Deferred to the backlog
- (none)
