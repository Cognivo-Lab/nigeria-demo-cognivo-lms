# .forge — how this product was built

Written by forge so the product's history travels with its code. It holds the
original interview, the build log, what the agents did, the verification record
and what the build cost.

This is a COPY for transport. The originals live in .git/forge/, which survives
the `git clean -fdx` a build agent may run. Deleting this directory loses
nothing — forge writes it again on the next publish.
